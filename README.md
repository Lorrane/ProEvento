# 🚀 ProEventos

> 🧨 Primeiro commit, primeira aula, primeira etapa da jornada. Ainda não é o projeto final, mas já tá dando pra sentir a energia do caos organizado 😎

## 🏆 Sobre o projeto

Este é um projeto de eventos desenvolvido com:

- Angular 11 e 12
- ASP.NET Core 6 Web API
- Entity Framework Core 5
- ASP.NET Core Identity

Ou seja, estamos montando uma aplicação full-stack com frontend zica e backend que não treme na hora do desafio 💪

## ⚠️ Importante: esse commit é só a primeira aula

Bora ser real: esse commit contém apenas a primeira aula do curso. Então sim, estamos no começo da jornada, ainda estamos levantando a base, montando a estrutura e entendendo como esse negócio vai se encaixar.

👉 Em outras palavras: não é o projeto completo, não é o MVP pronta pra produção, e muito menos a versão "final boss".

Mas é o começo de uma história boa, e a gente vai evoluindo junto com o código. 🚀🔥

## 🎯 Visão geral da aplicação

O objetivo do sistema é gerenciar eventos, participantes e demais funcionalidades relacionadas ao cenário de organização de eventos.

A stack escolhida combina:

- Frontend moderno com Angular
- API REST robusta em ASP.NET Core
- Persistência com Entity Framework Core
- Segurança com ASP.NET Core Identity

Tudo isso em um combo que deixa o projeto com cara de profissional, mas sem perder a vibe de "a gente está aprendendo e curtindo o processo" 😅
